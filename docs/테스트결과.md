### 왜 못 돌았는지

자동 테스트는 로그인하지 않은 새 브라우저로 앱을 연다(채점 프로그램과 같은 방식).
그런데 배포된 앱이 **Streamlit 계정 로그인 화면으로 넘어간다.** 앱의 로그인 칸
(`login_submit`)이 끝내 나타나지 않아 90초 뒤 멈췄다.

쿠키 없이 요청했을 때의 응답이다. 두 줄이 계속 반복된다.

```
HTTP/1.1 303 See Other
location: https://share.streamlit.io/-/auth/app?redirect_uri=https%3A%2F%2Fstudy04teamapp-...
HTTP/1.1 303 See Other
location: https://study04teamapp-.../-/login?payload=...
```

`https://study04teamapp-.../healthz` 는 `HTTP 200` 을 준다. 즉 **앱 자체는 살아 있고,
공개 설정만 되어 있지 않은 상태**다.

### 왜 중요한지

공고 4.4절은 "로그인하지 않은 브라우저(시크릿 창)로 배포 주소를 열어 로그인 화면이
보이는지 확인" 하라고 한다. 채점 프로그램도 로그인하지 않은 브라우저로 앱을 연다.
지금 상태로는 채점 프로그램이 앱에 들어오지 못한다
— **공고 6.3절 2번(배포 주소가 열리지 않음)에 걸려 시나리오 점수가 0점**이 된다.

### 고치는 법

1. Streamlit Community Cloud 에서 이 앱을 연다
2. 오른쪽 아래 **Manage app** → 점 세 개 메뉴 → **Settings**
3. **Sharing** 탭 → "Who can view this app" 을
   **"This app is public and searchable"** 로 바꾼다
4. **Save** 를 누른다
5. 브라우저를 완전히 로그아웃한 상태(또는 다른 기기)에서 주소를 열어,
   Streamlit 로그인이 아니라 **앱의 학번/비밀번호 로그인 화면**이 바로 나오는지 본다

고친 뒤 아래 명령으로 다시 돌리면 이 표가 채워진다.

```bash
python tests/run_scenarios.py --scenario 쉬움 --app https://study04teamapp-ogbzsuzzuagzqdgrfoappsa.streamlit.app
```
